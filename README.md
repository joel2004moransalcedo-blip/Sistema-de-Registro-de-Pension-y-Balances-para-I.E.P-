## 📖 Descripción del Proyecto
Este proyecto es un sistema de escritorio desarrollado en **Java (NetBeans)** y **MySQL** para la Institución Educativa Privada (I.E.P.) Divino Niño. Su objetivo principal es automatizar y optimizar la gestión y control del registro de pagos de pensiones y balances financieros, reemplazando los procesos manuales y hojas de cálculo para reducir errores, pérdidas de información y mejorar la eficiencia operativa.

## ✨ Características Principales
*   **Autenticación Segura:** Sistema de Login para proteger el acceso a la información.
*   **Gestión de Pagos:** Registro, modificación y eliminación de pagos de estudiantes de forma automatizada.
*   **Base de Datos Relacional:** Almacenamiento seguro y estructurado utilizando MySQL.
*   **Generación de Reportes:** Creación automática de reportes financieros y comprobantes de registro de estudiantes en formato **PDF**.
*   **Cálculo de Balances:** Función de suma automática para obtener el balance total de los pagos registrados.

## 🛠️ Tecnologías Utilizadas
*   **Lenguaje:** Java (Programación Orientada a Objetos - POO)
*   **Entorno de Desarrollo (IDE):** Apache NetBeans
*   **Base de Datos:** MySQL
*   **Arquitectura:** Uso de arreglos (Arrays), Herencia, Polimorfismo y conexión a BD.

## 🎯 Objetivos del Sistema
*   Disminuir el tiempo de registro y evitar las largas colas de espera.
*   Prevenir la pérdida de datos y reducir los errores humanos.
*   Generar reportes precisos y oportunos para la toma de decisiones.

## 🚧 Limitaciones
*   Aplicación de escritorio local (No disponible para plataformas móviles Android/iOS).
*   No incluye un sistema de recordatorios de pagos automáticos.
*   No genera gráficos estadísticos visuales.

## 👨‍💻 Estructura y Funcionamiento
El proyecto está estructurado mediante clases enfocadas en resolver tareas específicas:
*   `ControladorLogin` / `Vistalogin`: Gestión de acceso, validación de credenciales y protección del sistema.
*   `Guardar` / `ModificarDatos` / `Mostrar`: Clases encargadas del CRUD (Crear, Leer, Actualizar, Eliminar).
*   `Conectar`: Clase fundamental para la conexión a la base de datos MySQL.
